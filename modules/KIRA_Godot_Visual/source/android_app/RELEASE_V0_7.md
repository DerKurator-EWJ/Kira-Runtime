# Release v0.7 — Unified Mind / External Oven

## Added

- Native Android port of Equinox Language v0.3.
- Exact v0.3 BLAKE2b 63-bit semantic IDs.
- Tree/Mirror execution with synthesis + dissonance.
- Forest/Loom scheduling with non-propagating WAKE semantics.
- Universal domain-blind compute fabric.
- Persistent LOCAL MIND numeric triple layer.
- MIND settings page and source editor.
- MIND -> HYPNO WorkingSet projection.
- Forge v0.55 flat-kernel parser/resolver on Android.
- Digest-validated `.eqkernel.json` mount as read-only BASE.
- Optional external Hugging Face oven wrapper over Forge v0.56.

## Preserved

The original v0.6 Step46.2 sensor pipeline, HYPNO renderer, audio pipeline, profiles, legacy archive and legacy external knowledge importer remain in the project.

## Semantic boundary

The app does not run Hugging Face or Forge on-device. External knowledge is compiled outside Android, then mounted as a static flat kernel. The language/Fabric runtime is self-contained and remains usable with no external pack.
