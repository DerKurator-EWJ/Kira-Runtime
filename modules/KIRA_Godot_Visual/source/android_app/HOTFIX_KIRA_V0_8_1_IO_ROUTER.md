# Kira v0.8.1 — I/O Router + Infinite Now Gate

## Changes

- Top product dock now controls **input only**: text, microphone, camera.
- A fourth top control opens the **output menu**.
- Output menu toggles Kira text, ID flow, ID flow behind Kira, Das Tor zum Jetzt and Klang.
- Lower three symbols remain **view selectors only**.
- ID flow can be a dedicated full-screen view and can simultaneously sit behind Kira.
- Kira/Curator messages use translucent black glass surfaces so the ID field is attenuated only behind text.
- Composer reacquires focus after every send and asks Android to keep/reopen the keyboard.
- Relational sound output is again a first-class output toggle.
- Kira answers learned questions from the closest recalled relation (`◆ antwort`) instead of mirroring the question itself.
- Unknown input remains an honest learning/mirror state.
- Now Gate was rebuilt as an originless recursive tree matrix with off-screen virtual roots; branch spread collapses toward the tips until the tips become rays.
- Now Gate motion is a global field deformation rather than node-centred tree rotation.
