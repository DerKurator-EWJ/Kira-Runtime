# Kira v0.8.2 — Layered Backdrop / Persistent Matrix

This update removes the remaining main-view mode concept from the visible UI.

- top: three input switches + one output menu;
- output menu: text chat, background, Now Gate, sound;
- background submenu: uploaded image/video, ID matrix and effects;
- image refraction is driven by live MatrixActivityView droplet coordinates;
- video receives the same optical water-lens highlight/shadow field;
- matrix lanes persist across prompts and freeze only when Equinox is idle;
- chat messages and composer use translucent black glass;
- lower quick controls are shortcuts, not modes;
- text entry refocus after submit is retained from v0.8.1.
