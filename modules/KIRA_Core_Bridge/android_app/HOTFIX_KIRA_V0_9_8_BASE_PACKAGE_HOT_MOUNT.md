# Kira v0.9.8 — BASE Package / Validator / Hot Mount

- New `Kira BASE Package v1` (`.kirabase`) runtime format.
- SHA-256 validation for every payload plus aggregate payload digest.
- Teacher vectors are build evidence and are not mounted into runtime memory.
- Forge atoms/sequences become immutable BASE surfaces; Forge macro candidates become the F→Ω+n runtime hierarchy.
- Semantic relation polarity/evidence and traits are preserved as immutable BASE sidecars.
- BASE install is staged and directory-swapped; LIVE/PERSONAL memory is never rewritten.
- One previous BASE is retained for explicit rollback.
- Active BASE can be disabled (blank mode), replaced/updated, rolled back or removed without deleting personal memory.
- Legacy v0.9.7 `equinox_v06_base/store` layout migrates to `active/store` automatically.
- Native surface index lets the chat detect mounted `.kirabase` concepts without the legacy `.eqkernel` runtime.
- External oven includes `kira_base_package_v1.py` and `BASE_PACKAGE_V1.md`.
