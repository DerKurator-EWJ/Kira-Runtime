# Release v0.7.1 — Matrix Chat / Local Learning Surface

## Added

- CHAT button in the main Android product dock.
- Full conversation overlay with scrollable history and bottom composer.
- Persistent chat history.
- MATRIX, CLEAN and RAW rendering modes.
- Runtime display-mode switching without changing conversation state.
- Chat display controls in the MIND settings menu.
- Honest bootstrap reply planner: BASE match, local association, repeated input or unstable/no-knowledge response.
- Numeric local learning traces for chat role, normalized surface, token mentions and temporal adjacency.
- Chat activity projected into the existing MIND/HYPNO working state.

## Preserved

- Equinox Language v0.3 semantics.
- Forest/Loom wake boundary.
- Universal semantic compute fabric.
- Forge v0.56 external oven and read-only flat-kernel mount.
- Existing HYPNO, sensor, archive, capture and audio paths.

## Semantic boundary

The chat surface is not presented as a trained LLM. Without sufficient BASE/local structure it explicitly reports that no stable answer exists and stores the input as a local trace. Display styles affect rendering only.
