# Kira v0.9.1 – DREAM World Runtime

Adds the first persistent DREAM world engine: bootstrap world generation, routed live modulation, autonomous/reactive/instrument/fusion control modes, a dedicated world renderer, shared Dream->Orchestra state and a native Oven/Forge knowledge bridge.

DREAM runs without learned data. Learned local macro state and future externally compiled knowledge can modulate the same runtime instead of replacing it.
