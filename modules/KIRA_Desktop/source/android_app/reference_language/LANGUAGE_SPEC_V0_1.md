# Equinox Language v0.1 — Semantic Contract

## 1. Fundamental object

A tree is one identity with two opposed directional spaces. The language does not assign truth status to either side.

`TREE(X) = (X, T_X, A_X, M_X)`

- `X`: trunk / identity
- `T_X`: thesis space (crown direction)
- `A_X`: antithesis space (root direction)
- `M_X`: mirror relation preserving both

## 2. Mirror result

Mirroring does not select a winner and does not delete either input.

`M(T, A) -> (S, D)`

- `S`: synthesis = shared structural frame / exact agreement that can be represented without erasing either side
- `D`: dissonance = preserved structural difference / anti-synthesis

Both `S` and `D` are ordinary nodes. Either can acquire its own thesis and antithesis children and be mirrored again. This is the executable basis of double recursion.

## 3. No automatic exponential expansion

The machine never recursively expands a newly produced node merely because expansion is possible. Recursion requires an explicit refinement/wake operation.

## 4. Open infinity

`HOLD_INFINITY` means:

> continuation is permitted, no completion is required, and no computation is currently scheduled.

It is not a numeric infinity value and not an assertion that an actually completed infinite object exists.

## 5. Seal

`SEAL` converts the finite current tree into a stable macro identity. Current frontier nodes become `HOLD_INFINITY`. The tree can later be reactivated locally.

Therefore:

`SEALED != eternally immutable`

and

`HOLD_INFINITY != finished`

## 6. Local reactivation

`WAKE(node)` activates only the addressed node. `REFINE(node, side, structure)` extends that local branch. Unrelated siblings remain suspended.

## 7. Extinction / identity retirement

`EXTINCT` is never an automatic consequence of contradiction, inactivity, or branch pruning. It is an explicit whole-identity retirement operation reserved for the stronger case where the tree identity itself is no longer active/useful. Historical structure remains representable.

## 8. Numeric compilation

A sealed tree compiles to deterministic positive integer identities and triples of the form:

`(subject_id, relation_id, object_id)`

The thesis/antithesis/synthesis/dissonance roles are represented by numeric relations rather than special non-numeric storage.

## 9. v0.1 non-goals

v0.1 does not yet define:

- automatic antithesis generation,
- relevance-based cross-tree wake propagation,
- a forest/world scheduler,
- learned process macros,
- natural-language semantics,
- replacement/extinction heuristics,
- pretty final syntax.

Those are subsequent language/runtime layers, not assumptions hidden in the v0.1 core.
