# Kira v0.8.7 — Dialectic Runtime / Bootstrap Generators

This release makes the non-chat outputs operational from an empty memory and separates Kira's internal relation loop from the ordinary conversation surface.

## Chat
- Kira's normal bubble contains only the result: e.g. `gelernt`, `verbunden`, `noch offen`, or the selected recalled statement.
- `AUSGABEN → TEXT-CHAT → RELATIONSWEG` independently exposes the internal mirrored relation path on a subdued black-glass slab.
- Old mirror-style history is compacted on display without rewriting the stored history.

## Thesis / antithesis runtime
- `DialecticDecisionEngine` projects any active text/audio/vision macro into competing thesis and antithesis support.
- Both branches use the existing unbounded abstraction alphabet F, E, D, C, B, A, S, SS, SSS, Ω, Ω+n.
- The most stable branch can select among contradictory recalled text statements.
- `AUSGABEN → THESE / ANTITHESE TIERS` toggles two minimal glass bands above chat: light thesis, dark antithesis.

## Bootstrap video
- `ProceduralFilmView` generates moving frames from the FILM directive even with no media and no learned memory.
- If a selected background medium is active, the existing media renderer owns the film transformation instead.

## Bootstrap orchestra
- With no learned audio macros, Orchestra now creates a quiet oscillator-only seed ensemble.
- As soon as learned macro voices exist, they replace the seed bed automatically.

The shared memory architecture and per-core-mode stimulus masks remain unchanged.
