# Kira Runtime – Historical Development Archive

This repository contains independently archived experimental components
of the Kira/RRM runtime, desktop integration, and Godot visualization.

Each Git commit adds or replaces the current snapshot of **one** module.
Earlier states are available through Git tags. Different module families
are kept in separate directories under `modules/`.

**Historical note:** All commits were imported retrospectively. The Git
commit dates describe the import, **not** the original development dates.
The cross-module sequence is a logical presentation order, not a proven
chronological sequence. This archive is experimental and not validated
as one integrated, runnable system.

## Use

Select the relevant Git tag to inspect an older snapshot. For usage,
requirements, and tests consult the documentation inside each module.
Individual modules may have separate dependency and execution requirements.
